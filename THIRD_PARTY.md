# Third-party code and data

html is MIT (`LICENSE`). No upstream code is adapted: the tokenizer and the tree builder are written for this repository from the standard's text. Three upstream artifacts define what that code must do, and two ship here as test data.

## HTML Living Standard

- Upstream: https://html.spec.whatwg.org/
- License: CC BY 4.0
- Read: §13.2 Parsing HTML documents and §13.4 Parsing HTML fragments, as published on 2026-10-30

The parsing section is the reference for `src/Tokenizer.zig` and `src/Parser.zig`. The tables in `src/Parser.zig` (quirks-mode public identifiers, SVG tag and attribute names, foreign attributes) are the standard's. `src/entities.zig` is generated by `tools/entities.py` from the standard's named character reference table, https://html.spec.whatwg.org/entities.json, so it carries that table's data.

## html5lib-tests

- Upstream: https://github.com/html5lib/html5lib-tests
- License: MIT, in `test/html5lib-tests/LICENSE`, kept verbatim
- Pinned commit: `c777c408b61078ea2eb4acefc2535f54dbc8b28a`

`test/html5lib-tests/tokenizer/` holds the tokenizer corpus, vendored as data. `test/tokenizer.zig` reads it at test time. It is not compiled into the library and is not listed in `build.zig.zon`'s `paths`, so a `zig fetch` tarball does not carry it.

## web-platform-tests

- Upstream: https://github.com/web-platform-tests/wpt
- License: 3-Clause BSD, in `test/wpt-tree-construction/LICENSE.md`, kept verbatim
- Pinned commit: `70dae60789ef6220d9b4e60c92c5b2107b4e2b93`

`test/wpt-tree-construction/` holds the `.dat` files and `README.md` of `html/syntax/parsing/resources`, vendored as data, except the `scripted_*.dat` files, which need a script engine. `test/tree.zig` reads them at test time. Like the tokenizer corpus, they are not compiled into the library and not in a `zig fetch` tarball.
